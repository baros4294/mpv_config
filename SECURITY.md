# Security policy

Report security problems privately through the repository's **Security** tab (**Report a vulnerability**), not in a public issue. Examples: a config line that makes mpv load or run something it shouldn't, or a bundled file that differs from its upstream release.

Problems in uosc or thumbfast themselves belong upstream: [uosc](https://github.com/tomasklaen/uosc/security), [thumbfast](https://github.com/po5/thumbfast). This repository picks up their fixes through the weekly update pull request.

You'll get a reply within a week. Only the latest version on `main` is maintained.
